# Librería HDrive
Esta librería permite controlar de manera mucho mas eficiente y sencilla una gran variedad de drivers para motor CD, con esto proyectos que requerian cientos de líneas de código, ahora pueden comprimirse a solo unas decenas.
## Funciones

  - Avance en 4 direcciones (Adelante, Atrás, Izquierda y Derecha)
  - Frenos
  - Rodada libre
  - Prueba de Driver
  
## Drivers Compatibles

  - Arreglo de transistores personalizado
  - TB6612FNG
  - L298N
  - L293D
  - DRV8870(Sin probar)
  
# HDrive Library
This library allows you to control in a much efficient and easy way a great variety of DC Motor drivers, with this, proyects that would requiere hundreds of code lines, can be done in a few tens.
## Features

  - Drive in 4 directions (Front, Back, Left, Right)
  - Break
  - Free run
  - Driver Test
  
## Compatible Drivers

  - Custom transistor array
  - TB6612FNG
  - L298N
  - L293D
  - DRV8870(Not tested)

Version: 2.0.0 (beta)
